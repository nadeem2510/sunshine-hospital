## Blog Writing Guidelines

### Title Format
- Use numbers: "7 Signs You Need to See an Orthopedic Doctor"
- Use "How to": "How to Claim ESIC Benefits at Sunshine Hospital"
- Include location: "Best Trauma Care in Sambhajinagar"

### Content Structure
1. **Introduction** (100-150 words)
   - Hook the reader
   - State the problem
   - Preview the solution

2. **Main Content** (800-1200 words)
   - Use H2 and H3 headings
   - Include bullet points
   - Add relevant statistics

3. **Call to Action** (50-100 words)
   - Book appointment
   - Call for consultation
   - Visit hospital

### Image Guidelines
- Use hospital/doctor images where possible
- Add descriptive alt text with keywords
- Compress images for fast loading
